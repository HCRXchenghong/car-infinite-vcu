# VCU 板硬件设计（S32K358）

> 状态：设计准备。本文档基于已确定的系统级决策（见项目根目录 01~09 文档）；标注"待定"的项目需确认后才能画原理图。

## 1. 板卡定位

- 整车唯一决策节点：运动仲裁、避障决策、功率管理、上电时序管理、诊断中心（见 `01-整车电子电气架构.md` §2.1）
- 工作模式仲裁与遥控接收（本地遥控直连本板，见 01 §7）
- **不参与**车身电器驱动（那是 BCM 的职责）

## 2. 主控

- **NXP S32K358GHT1MPCST**（锁步 M7 @240MHz，8MB Flash，8×CAN-FD，1G ENET，HSE-B，HDQFP-172-EP，12NC 935461958557）
- 降本备选（引脚兼容）：S32K348GHT1MPCST（已在 02 文档记录）

## 3. 电源树

```
12V 输入（防反接 + TVS + 支路保险）
├─ 12V→5V buck ≥2A（型号待定）
│   ├─ 5V→3.3V（MCU VDD 及外设）
│   ├─ 3.3V→1.2V 核心电源（按数据手册要求）
│   └─ CAN 收发器 5V 供电
└─ 电源管理方案（已定）：**车规 SBC（NXP FS26，集成窗口看门狗/电压监控/复位）**，全车四块 S32K3 板统一
```

## 4. 接口分配（外设级）

| 功能 | 外设 | 数量 | 说明 |
|---|---|---|---|
| 主干 CAN（500K） | FlexCAN | 1 | 接前桥/后桥/BCM/BMS；**TJA1443 车规 CAN-FD 收发器（已定，向下兼容 CAN 2.0，全车统一用此料）**；两端 120Ω |
| 遥控接收机（SBUS） | LPUART | 1 | 2.4G 遥控接收机直连（01 §7，优先级最高）；5V 从本板取电（若长线干扰实测明显再改隔离供电） |
| 调试串口 | LPUART | 1 | 打印/标定 |
| 预留 CAN | FlexCAN | 2 | 1 路预留给机械臂控制网段（达妙电机，1Mbps，与转向同构；臂视觉链路见以太网行）；余 1 路扩展/备用 |
| 以太网 | ENET MAC + PHY | 1 | **已定稿（本期直接贴满三路，三口同时在线）**：MAC → SJA1105Q 车载交换芯片（RGMII 1G 上联，SPI 配置，固件开机初始化）；交换机后挂：① RTL8211F → RJ45 千兆口（带 TVS/ESD 保护），用于 Mid-360/上位机组网/调试诊断；②③ TJA1104 双口 PHY → 2×车规 T1 口，预留接惯导/臂视觉等待用（臂视觉数据不一定走 T1，预留待用）；保留千兆直连路径 0Ω 备用（交换芯片故障时可切换直连）；切换用 0Ω 电阻，不用跳线帽（高速信号桩线会破坏信号质量）；整网可再经车载交换机（车上已有设备）组网；机械臂控制仍走预留 CAN 段 |
| 调试口 | SWD | 1 | |
| GPIO 预留 | GPIO | ≥10 | 摄像头帧同步触发线 ×2 **必做**（引线到摄像头位，AHD→GMSL 演进，见 01 §8）；余量拉排针 |
| 时钟 | FXOSC | 8~40MHz 晶振（频率待定） | 32kHz SXOSC 可选 |

## 5. 外围电路清单

- 复位/看门狗/电压监控：由 SBC（FS26）集成提供（已定）
- CAN 保护：TVS + 共模电感（每路）
- SJA1105Q 交换芯片：SPI 配置接口 + 复位脚（MCU 开机初始化交换机，本期贴装）
- BOOT 配置、HSE 相关按参考设计
- 参考设计：NXP 官方 S32K358 评估板原理图可借鉴
