# VCU 板硬件设计（S32K358）

> 状态：设计准备。本文档基于已确定的系统级决策（见项目根目录 01~09 文档）；标注"待定"的项目需确认后才能画原理图。

## 1. 板卡定位

- 整车唯一决策节点：运动仲裁、避障决策、功率管理、上电时序管理、诊断中心（见 `01-整车电子电气架构.md` §2.1）
- 工作模式仲裁与遥控接收（本地遥控直连本板，见 01 §7）
- **不参与**车身电器驱动（那是 BCM 的职责）

## 2. 主控

- **NXP S32K358GHT1MPCST**（锁步 M7 @240MHz，8MB Flash，8×CAN-FD，1G ENET，HSE-B，HDQFP-172-EP，12NC 935461958557）
- 内核配置：1 个锁步对 + 1 颗独立 Cortex-M7，共 3 核 @240MHz（独立核可承担通信栈/诊断/时间同步等非安全任务，见 02 §2.3）
- 降本备选（引脚兼容）：S32K348GHT1MPCST（已在 02 文档记录）

## 3. 电源树

```
12V 输入（工作电压范围建议 9~16V；防反接 + TVS + 支路保险；
         瞬态耐受目标 ISO 7637-2 / ISO 16750-2，TVS 钳位电压与后级 buck 输入耐压配合选取）
├─ 12V→5V buck ≥2A（型号待定，见 §6）
│   ├─ 5V→3.3V（MCU VDD 及外设）
│   ├─ 3.3V→1.8V（SJA1105Q 及 PHY 供电轨，纳入电源树）
│   └─ CAN 收发器供电（主干为隔离收发器，供电形式随选型定）
└─ 电源管理方案（已定）：**车规 SBC（NXP FS26，集成窗口看门狗/电压监控/复位）**，全车四块 S32K3 板统一
```

> 核心电源说明：S32K358 内核低压轨（约 1.1V）由片内调节器产生，板级典型只需 3.3V 主供，原"3.3V→1.2V"行作废；仅当需要 Full Performance 模式时才按数据手册提供外部 1.5V 轨（本设计暂不启用，列入 §6 待确认）。

|---|---|---|---|

| 遥控接收机（SBUS） | LPUART | 1 | 2.4G 遥控接收机直连（01 §7，优先级最高）；5V 从本板取电（若长线干扰实测明显再改隔离供电）；**SBUS 为反相 100kbps 8E2 信号，S32K3 LPUART 无硬件反相，需外置反相电路（单管或 74LVC1G04 类）** |

| 以太网 | ENET MAC + PHY | 1 | **已定稿（本期直接贴满三路，三口同时在线）**：MAC → SJA1105Q 车载交换芯片（RGMII 1G 上联，SPI 配置，固件开机初始化）；交换机后挂：① RTL8211F → RJ45 千兆口（带 TVS/ESD 保护），用于 Mid-360/上位机组网/调试诊断；**RTL8211F 为商用级（0~70℃）风险件：限调试/上位机组网用途，车规量产场景需评估替代；RJ45 侧按车规防水方案（如 M12 转接）**；②③ TJA1104（**双口 100BASE-T1 PHY，两路车规 T1 口均为百兆**；管理接口为 MDIO 或配置脚，按数据手册接入）→ 2×车规 T1 口，预留接惯导/臂视觉等待用（臂视觉数据不一定走 T1，预留待用）；保留千兆直连路径：**采用选焊/交叉点方案（不用 0Ω 切换、不用跳线帽），桩线长度在布局时严格控制（按参考设计取最短，避免桩线破坏信号质量）**；整网可再经车载交换机（车上已有设备）组网；机械臂控制仍走预留 CAN 段 |

| GPIO 预留 | GPIO | ≥10 | 摄像头帧同步触发线 ×2 **必做**（引线到摄像头位，AHD→GMSL 演进，见 01 §8）；余量拉排针 |

## 5. 外围电路清单

- 复位/看门狗/电压监控：由 SBC（FS26）集成提供（已定）
- CAN 保护：TVS + 共模电感（每路）
- SJA1105Q 交换芯片外围（本期贴装）：SPI 配置接口（LPSPI ×1，见 §4）+ 复位脚 + 中断脚 + MDIO；**自身 25MHz 晶振**（交换参考时钟，独立于 MCU 晶振）；1.8V/3.3V 供电轨已纳入 §3 电源树（MCU 开机初始化交换机）
- TJA1104：双口 100BASE-T1 PHY（两路车规 T1 口均为百兆），管理接口为 MDIO（或配置脚），按数据手册接入；TJA1103 字样作废，统一按 TJA1104
- RTL8211F：商用级（0~70℃）风险件——限调试/上位机组网用途，车规量产场景需评估替代；RJ45 侧按车规防水方案（如 M12 转接）
- SBUS 反相电路：SBUS 为反相 100kbps 8E2 信号，S32K3 LPUART 无硬件反相，外置单管或 74LVC1G04 类反相（对应 §4 遥控行）
- SWD 调试接口预留：统一接口定义（SWDIO/SWDCLK/SWO/nRESET + 3.3V/GND，10-pin 1.27mm）；BOOT 配置脚按 S32K3 参考设计下拉（内部 Flash 启动，HSE 相关按参考设计）；TEST 脚接 GND（数据手册正常工作配置，禁止悬空）
- 参考设计：NXP 官方 S32K358 评估板原理图可借鉴

## 6. 待确认问题（本板板级问题已清，仅剩等厂家/实物/选型类）

1. FXOSC 晶振频率（8~40MHz 范围内，定参考时钟方案时确认）
2. 12V→5V buck 型号（≥2A 车规，按 09 §3 选购五参数选型）
3. **主干 CAN 隔离收发器选型**（ISO1042 类；2026-08-30 三域隔离定案，见 09 §4 / 11 §3.1；VCU 板主干通道同样按隔离收发器，型号待定）
4. RTL8211F 商用级（0~70℃）车规量产替代方案评估；RJ45 车规防水形式（如 M12 转接）确认
5. 是否需要外部 1.5V 轨（仅当启用 S32K358 Full Performance 模式，按数据手册定）
6. 12V 输入保护器件定料：按 9~16V 工作范围与 ISO 7637-2 / ISO 16750-2 瞬态目标，确定 TVS 钳位与后级 buck 输入耐压的配合
