# 送餐车底盘项目

> 车规级自动驾驶送餐车底盘 —— 项目总体说明与文档索引
> 文档整理日期：2026-08-30

---

## 1. 项目概述

本项目为一款**车规级自动驾驶送餐车**的底盘平台，核心特征：

- **四轮转向 + 四轮驱动（4WS/4WD）**：每个车轮独立转向、独立驱动，机动性强（支持小半径转向、差动辅助原地转向）
- **低速场景**：最高速度 25 km/h（软件留可配置限速档位：园区 8 / 非机动车道 15 / 测试场 25）
- **整车目标为车规级**：器件车规认证、ISO 26262 功能安全、环境可靠性、软件规范四个维度
- 执行层采用**成品 CAN 控制器**（达妙关节电机、一拖二伺服控制器），自研三块控制板（VCU + 前后桥）

## 2. 整车拓扑（最终定稿）

```
                 自动驾驶上位机（决策规划，非底盘范围）
                          │
                    ┌─────┴──────┐
                    │  VCU: S32K358 │  唯一决策者：运动仲裁/避障/功率管理/诊断中心
                    └─┬─────┬─────┬─┐
           主干 CAN 500K │     │     │ │
            ┌────────────┘     │     │ └───────────┐
            ▼                  ▼     ▼             ▼
     前桥 MCU: S32K344   后桥 MCU: S32K344   BMS（嘉佰达）  BCM: S32K312
     · 安全网关+急停反射  · 安全网关+急停反射             · 上盖开合/灯光/远程开机/警灯功放/5G路由器电源
     · 前传感器汇聚(6路)  · 后传感器汇聚(6路)
            │                  │
     桥内 CAN(1M/厂家)    桥内 CAN(1M/厂家)
     ├ 2× 达妙 J10010     ├ 2× 达妙 J10010
     └ 1× MSSD 伺服       └ 1× MSSD 伺服
        （前2轮毂电机）       （后2轮毂电机）
```

**职责铁律：决策权永远在 VCU，桥端只有"执行 + 否决权"（往安全方向的急停反射）。**
