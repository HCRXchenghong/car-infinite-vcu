# BCM 板硬件设计（S32K312）

> 状态：设计准备。依据 `08-车身控制器（BCM）方案.md`、`09-全车供电与线路分配.md` 已确定内容。
> 本板是四块 S32K3 控制板（含显示板共五块自研板）中功率输出最多的一块，布局上**功率区与逻辑区严格分开**。

## 1. 板卡定位

- 车身电器执行中心：上盖机构、灯光、5G 路由器/上位机/屏幕电源、风扇、功放、警灯
- 常电待机节点：4G 唤醒守夜 + 整车上电时序执行（08 §5.1）
- 舱内环境监测（温湿度）与模式指示
- 不参与行驶安全链路（QM 域）

## 2. 主控（已确定）

- **NXP S32K312NHT0MPBST**（单核 M7 @120MHz，2MB Flash，6×CAN-FD，8×UART，**143 IO**（HDQFP-172，NXP 官方）；网传"77 GPIO"为 100 脚裁剪版的数值，不适用本封装，12NC 935436148557）
- 开发板：S32K312EVB-Q172

## 3. 电源树

```
12V 输入（防反接 + TVS + 支路保险）——分两路进板（针脚表冻结 v1.3（2026-08-31，11 §4））：
  · 逻辑输入：主连接器芯 4/5（12V+）+ 6/7（GND），供逻辑区（~1A）
  · 功率级大电流输入：从 12V 母线单独拉线（独立保险 50A（定案见 11 §4.3：受控负载同时峰值约 40A），大电流端子），直入功率区，不经主连接器
├─ 12V→5V buck ≥2A
│   ├─ 5V→3.3V（MCU VDD）
│   ├─ 12V→3.8~4.2V buck ≥2A（建议 ≥3A，待机域独立）+ 大电容（4G 模块专用，搜网峰值 ~2A，禁 LDO；由 12V 直接降压，不走 5V 转接）
│   ├─ I2C 上拉 / 传感器供电（SHT31 ×2）
│   └─ CAN 收发器 5V
├─ 12V 功率输出区（见第 5 节）：经高边开关/继电器输出，继电器线圈 12V 直驱 + 三极管开关控制，线圈并联续流二极管；继电器具体型号待定，触点容量按负载选；线圈控制信号来自 MCU GPIO，经三极管/小 MOS 驱动
└─ 常电设计：4G 模块 + MCU 待机域常供电；其余功率输出默认断电，按上电时序逐级开启；电源管理方案（已定）：车规 SBC（NXP FS26，含窗口看门狗/复位/电压监控），与全车统一。
   常电待机功耗预算（占位，待实测）：主模块空载（电源链静态电流）＋ 4G 模块 PSM 深睡电流 ＋ MCU 待机（STOP/STANDBY）电流；据此评估整车停放天数。
   前提：常电链路（电池→保险→BCM 逻辑输入，见 09/11）成立，且停放期间无其他常电负载超额。
```

> 继电器数量由暂按 8 只改为 **6 只**（警灯 ×2 改高边直驱；剩：路由器/上位机/屏/风扇/功放/摄像头组），最终以使能方案定稿为准。
> 灯具实际电流待各灯具规格书锁定后按通道校核；BTS7200 支持双通道并联扩流。
> 转向灯为通电自闪型；刹车灯由 VCU 经 CAN 请求；LED 矩阵灯按整灯通断驱动（用户确认）。
> 电磁锁为感性负载，对应高边通道须外接反激续流二极管。
> **防夹边界**：推杆堵转电流须 <5A 额定，防夹检测阈值按 FB 采样整定（6.5A 限流点表述以数据手册核实为准）。
> **灯光出线座芯位说明（23 芯，针脚表冻结 v1.3（2026-08-31，11 §4））**：芯 20~23 已改配为 3 路受控输出（含上装灯/机械臂控制器 12V）+GND，无纯备用芯；完整针脚表见 11 §4.6。

## 6. 外围电路清单

- 每只继电器：三极管/MOS 驱动 + 续流二极管 + 状态反馈（可选）
- 高边开关：输入端串阻与去容按数据手册配置；电磁锁通道外接反激续流二极管；诊断 SPI 总线共享 + 片选/状态脚接 MCU
- CAN 保护（TVS + 共模电感）；主干隔离 CAN 收发器待选型（见 09/11 定案）；电源管理（已定）：车规 SBC（NXP FS26），与全车统一
- 4G 模块：SIM 卡座（Nano）、天线接口（IPEX，天线位置整车定）、去容与大电容（≥470µF 级）
- 复位电路、看门狗策略与全车统一（SBC FS26 提供窗口看门狗/复位/电压监控）
- SWD 调试接口预留（SWCLK/SWDIO + 复位，排针/焊盘）
- BOOT 脚配置方案：按数据手册配置 NVM boot 入口（BOOT_CFG/TEST 脚），预留烧录/调试切换焊盘或跳线
