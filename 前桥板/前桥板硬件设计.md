# 前桥板硬件设计（S32K344）

> 状态：设计准备。**后桥板与本板完全同设计**（仅传感器编号与装车位置不同，见第 6 节），画一版板子两块通用。
> 本文档基于已确定的系统级决策；标注"待定"的项目需确认后才能画原理图。

## 1. 板卡定位

- 安全网关 + 本地急停反射 + 传感器汇聚（见 `01-整车电子电气架构.md` §2.2）
- 职责：接收 VCU 目标指令转发本桥执行器；汇聚 7 路传感器上报（超声×5 + 激光×2，见 05 §2）；本地急停反射（见 06 §4）
- 本地急停反射执行接口：经桥内 CAN 禁能指令（达妙失联保护配置 + MSSD 禁能帧），无独立硬线；硬线直切路径见 06 §5，不经桥板
- 铁律：只有执行权 + 往安全方向的否决权，无决策权

## 2. 主控

- **NXP S32K344EHT1MPBST**（锁步 M7 @160MHz，4MB Flash，16×LPUART，6×FlexCAN，HDQFP-172）
- 采购注意：勿买 BGA257 封装版本（02 文档已强调）

## 3. 电源树

```
12V 输入（工作电压范围建议 9~16V；防反接 + TVS + 支路保险；瞬态耐受目标 ISO 7637-2 / ISO 16750-2）
├─ 12V→5V buck ≥2A（型号待定）
│   ├─ 5V→3.3V（MCU VDD 及外设）
│   └─ CAN 收发器供电（主干为隔离收发器，供电形式随选型定；桥内两路为 TJA1443 5V）
└─ 电源管理方案（已定）：车规 SBC（NXP FS26），与全车统一
```

> 传感器 5V：**来自整车隔离 5V/2A/10W 模块，经传感器聚合座（23 芯，芯 13）直接入板，本板不做转换**（定案，见 09 §1/§2、11 §4.5）。
> 核心电源说明：S32K344 内核低压轨（约 1.1V）由片内调节器产生，板级典型只需 3.3V 主供（原"3.3V→1.2V"行按 S32K3 家族实况作废，与 VCU 板 §3 一致）。

## 5. 外围电路清单

- 复位/看门狗策略由 SBC（FS26）提供，与 VCU 板统一
- 每路 CAN：收发器 + TVS + 共模电感；**终端电阻：主干——桥板非端点，120Ω 为可选贴装位，默认不贴（主干 120Ω 仅两端贴装：VCU 端 + 线束最远节点端，见 11 §3.1，按整车布线定稿）；桥内转向/驱动两路——桥板端贴 120Ω**
- 传感器接口：5V 供电取自整车隔离 5V（经聚合座芯 13 直接入板，本板不做转换）+ 信号防串扰布线（功率区与传感器区分开，05 文档）
- 跨域处理（隔离 5V 域 → 本板）：隔离域 GND 与本板地经 **1MΩ + 100nF 软接**（仅作静电泄放与高频参考，非电位钳位）；UART 共模电压列实测项，超限备选光耦/隔离 UART 方案（见 11 §4.5）
- SWD 调试接口预留：统一接口定义（SWDIO/SWDCLK/SWO/nRESET + 3.3V/GND，10-pin 1.27mm）；BOOT 配置脚按 S32K3 参考设计下拉（内部 Flash 启动）；TEST 脚接 GND（数据手册正常工作配置，禁止悬空）

## 7. 待确认问题

1. MSSD 伺服控制器 CAN 波特率（协议格式已知为类 CANopen，见上表）——等厂家手册
2. 桥内驱动网段是否与转向合并待实测（01 §3 注），CAN 布线预留合并可能性；主干隔离收发器选型随 09 §4 / 11 §3.1 定料，主干 120Ω 可选贴装位是否贴装随整车布线定稿确认

## 8. 已确认事项（2026-08-30）

- 电源管理：车规 SBC（NXP FS26），全车统一（用户确认）；CAN 收发器：主干必须使用隔离 CAN 收发器（待选型，ISO1042 类；2026-08-30 三域隔离定案，见 09 §4 / 11 §3.1），TJA1443 仅限桥内 CAN 使用
- 传感器 5V：来自整车隔离 5V/2A/10W 模块，经传感器聚合座（23 芯，芯 13）直接入板，本板不做转换（见 09 §1/§2、11 §4.5）
- 终端电阻布置：主干 120Ω 仅两端贴装（VCU 端 + 线束最远节点端），桥板主干为可选贴装位默认不贴；桥内两路 CAN 桥板端贴 120Ω（见 11 §3.1/§3.2）
- 达妙电机 48V 供电**不经过桥板**：配电端直接拉线到电机，桥板只走 CAN 信号（用户确认）
