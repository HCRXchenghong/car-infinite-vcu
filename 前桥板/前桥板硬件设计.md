# 前桥板硬件设计（S32K344）

> 状态：设计准备。**后桥板与本板完全同设计**（仅传感器编号与装车位置不同，见第 6 节），画一版板子两块通用。
> 本文档基于已确定的系统级决策；标注"待定"的项目需确认后才能画原理图。

## 1. 板卡定位

- 安全网关 + 本地急停反射 + 传感器汇聚（见 `01-整车电子电气架构.md` §2.2）
- 职责：接收 VCU 目标指令转发本桥执行器；汇聚 6 路传感器上报；本地急停反射（见 06 §4）
- 铁律：只有执行权 + 往安全方向的否决权，无决策权

## 2. 主控

- **NXP S32K344EHT1MPBST**（锁步 M7 @160MHz，4MB Flash，16×LPUART，6×FlexCAN，HDQFP-172）
- 采购注意：勿买 BGA257 封装版本（02 文档已强调）

## 3. 电源树

```
12V 输入（防反接 + TVS + 支路保险）
├─ 12V→5V buck ≥2A（型号待定）
│   ├─ 5V→3.3V（MCU VDD 及外设）
│   ├─ 3.3V→1.2V 核心电源（按数据手册）
│   ├─ CAN 收发器 5V
│   └─ 传感器 5V 独立一路（~300mA，与逻辑电源分开，05 文档要求）
└─ 电源管理方案（已定）：车规 SBC（NXP FS26），与全车统一
```

## 5. 外围电路清单

- 复位/看门狗策略由 SBC（FS26）提供，与 VCU 板统一
- 每路 CAN：收发器 + TVS + 共模电感 + 120Ω（主干与桥内各自两端）
- 传感器接口：5V 供电 + 信号防串扰布线（功率区与传感器区分开，05 文档）

## 6. 前/后桥差异说明

| 项 | 前桥 | 后桥 |
|---|---|---|
| 超声波编号 | 1~4 | 5~8 |
| 激光测距 | 前左/前右 | 后左/后右 |
| 达妙电机 | 前左/前右转向 | 后左/后右转向 |
| 伺服控制器 | 前 2 轮毂电机 | 后 2 轮毂电机 |
| 软件 | 同一固件，参数区分桥号 | 同左 |
