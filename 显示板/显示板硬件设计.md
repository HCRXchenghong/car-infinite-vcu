# 显示板硬件设计（STM32F407）

> 状态：设计准备。依据已确定的屏幕方案（`08-车身控制器（BCM）方案.md` §5.4）：STM32 + SPI 裸屏独立显示，屏幕域与操作系统隔离。
> 标注"待定"的项目需确认后才能画原理图。

## 1. 板卡定位

- 独立显示域：开机即播品牌动效，待机品牌页、取餐二维码页、关盖倒计时页
- 上位机只发内容数据（二维码内容、倒计时秒数），不碰显示控制——屏幕永远看不到 Ubuntu
- 不属于行驶安全链路

## 2. 主控（已确定）

- **STM32F407**（具体子型号待定，建议 F407VGT6：1MB Flash / 192KB RAM / 100 引脚，动画资源+LVGL 够用）
- 板卡形态（已定）：**自画定制板**，按采购的屏幕接口适配设计（不用核心板）
- 软件栈：LVGL + qrcodegen（成熟移植多）

## 3. 电源树

```
12V 输入（防反接 + TVS）
├─ 12V→5V buck（屏幕供电 + 背光驱动；额定电流 🔲 待屏型号登记后按屏功耗核算）
│   └─ 5V→3.3V（MCU 与屏幕逻辑）
└─ 背光驱动：5V → MOS 管 PWM 调光（MCU PWM 控制）
```

- 屏幕供电直接上电（不设延迟上电使能线：STM32 上电即播品牌动效，不会暴露系统画面，用户确认）；待机断电由 BCM 显示板电源继电器管理
- 背光注：背光 LED 串正向压降待屏规格确认，若 >5V 需改用升压驱动方案（🔲 随屏规格登记关闭）

## 4. 接口分配（外设级）

| 功能 | 外设 | 数量 | 说明 |

| 背光 | TIM PWM | 1 | 驱动 MOS 调光 |

## 5. 外围电路清单

- 复位电路：定为**复位芯片**（常用型号占位：SGM809/STM6315 类，具体型号待选）
- 看门狗：本板属 QM 域、非安全关键，采用 MCU **内部 IWDG**，不加外部看门狗器件（与全车策略一致：安全域由 SBC 窗口看门狗保障）
- BOOT0/刷写：BOOT0 经跳线/电阻焊盘选择，支持 **DFU（USB）**与串口（UART）刷固件，量产前用 DFU 烧录，现场升级经上位机转发亦可走串口/USB
- 屏幕 FPC/排针接口（按所选屏幕定）
- 背光 MOS + 限流；屏幕电源去容

## 6. 环境要求（显示板装于餐箱外）

- **防水**：板卡装于餐箱外部，连接器建议 IP65 以上（含屏体与接插件密封）；整机防溅/冲洗场景需覆盖本板 🔲 待办：外壳/灌封防护方案（外壳形式、灌封胶选型、屏窗口密封）
- **日晒高温/凝露**：户外直晒与昼夜温差会导致高温与内部凝露，器件温度等级与三防涂覆需评估 🔲 待办（高温降额与凝露对策待整车环境规格确定）
- **户外可视性**：阳光下可读，屏亮度/防眩与背光余量需评估 🔲 待办（随屏规格登记）
- 供电与信号线按户外线束要求走线（见 11）
