# 显示板硬件设计（STM32F407）

> 状态：设计准备。依据已确定的屏幕方案（`08-车身控制器（BCM）方案.md` §5.4）：STM32 + SPI 裸屏独立显示，屏幕域与操作系统隔离。
> 标注"待定"的项目需确认后才能画原理图。

## 1. 板卡定位

- 独立显示域：开机即播品牌动效，待机品牌页、取餐二维码页、关盖倒计时页
- 上位机只发内容数据（二维码内容、倒计时秒数），不碰显示控制——屏幕永远看不到 Ubuntu
- 不属于行驶安全链路

## 2. 主控（已确定）

- **STM32F407**（具体子型号待定，建议 F407VGT6：1MB Flash / 192KB RAM / 100 引脚，动画资源+LVGL 够用）
- 板卡形态（已定）：**自画定制板**，按采购的屏幕接口适配设计（不用核心板）
- 软件栈：LVGL + qrcodegen（成熟移植多）

## 3. 电源树

```
12V 输入（防反接 + TVS）
├─ 12V→5V buck（屏幕供电 + 背光驱动）
│   └─ 5V→3.3V（MCU 与屏幕逻辑）
└─ 背光驱动：5V → MOS 管 PWM 调光（MCU PWM 控制）
```

- 屏幕供电直接上电（不设延迟上电使能线：STM32 上电即播品牌动效，不会暴露系统画面，用户确认）；待机断电由 BCM 显示板电源继电器管理

## 4. 接口分配（外设级）

| 功能 | 外设 | 数量 | 说明 |
|---|---|---|---|
| TFT 屏 | SPI | 1 | **4.58 寸 TFT（采购成品，型号/驱动 IC 待用户登记）**；含 CS/DC/RST 控制脚；画板前需屏幕接口/时序资料 |
| 背光 | TIM PWM | 1 | 驱动 MOS 调光 |
| 内容数据串口 | USART | 1 | **上位机直连（已定）**：临滴科技 RK3588 板（USB 转串口接入） |
| 外部 Flash（预留焊盘，暂不贴） | SPI | 1 | W25Q 系列；动画资源 <500KB 时 F407 内部 Flash 够用，超出再加贴；预留焊盘免二次改板 |
| 调试口 | SWD | 1 | |
| GPIO 预留 | GPIO | ≥4 | |
| 时钟 | HSE | 8MHz 晶振（常规方案） | |

## 5. 外围电路清单

- 复位电路（RC 或复位芯片）
- 屏幕 FPC/排针接口（按所选屏幕定）
- 背光 MOS + 限流；屏幕电源去容
- BOOT 配置（支持 DFU/串口刷固件为佳）
